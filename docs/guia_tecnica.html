Entorno y estructura del proyecto

Para todos los squads

Cada proyecto Python vive en su propio entorno virtual: una carpeta .venv con su propio intérprete y sus librerías. Así lo que instalas para TalentScope no rompe otros proyectos, que es lo que le pasa hoy al Python del sistema de muchos computadores.

# Windows (PowerShell)
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install -e .          # instala el paquete talentscope en modo editable

# Linux / Mac
python3 -m venv .venv
source .venv/bin/activate

El código vive en src/talentscope/. Por eso los imports son absolutos y empiezan por el paquete:

from talentscope.config import DATA_RAW_EXCEL        # bien

# from config import DATA_RAW_EXCEL                  # mal: solo funciona si ejecutas desde esa carpeta

Usa pathlib.Path para las rutas. Nunca escribas rutas absolutas de tu computador: ese es justamente el BUG-03.

02

HTTP con requests

Apoya BUG-04HU-10HU-16

Hacer scraping es, primero, pedir páginas. Cuando el navegador abre una URL envía una petición GET y recibe una respuesta con un código de estado, unos encabezados y un cuerpo (el HTML). requests hace lo mismo desde Python.

import requests

resp = requests.get(
    "http://localhost:8000/ofertas/pagina-1.html",
    headers={"User-Agent": "TalentScopeBot/0.3 (proyecto educativo)"},
    timeout=10,                     # segundos. SIN esto, el programa puede esperar para siempre
)
print(resp.status_code)             # 200 = OK, 404 = no existe, 500 = error del servidor
print(resp.headers["Content-Type"]) # text/html ... ¿dice charset?
resp.raise_for_status()             # lanza excepción si el código es 4xx o 5xx
html = resp.text

Codificación: por qué sale "MedellÃ­n"

resp.text convierte bytes en texto usando la codificación que adivina requests. Si el servidor no declara el charset, requests asume ISO-8859-1 y las tildes en UTF-8 salen dañadas. Revisa resp.encoding y resp.apparent_encoding, o fija la codificación antes de leer .text.

print(resp.encoding, resp.apparent_encoding)   # p. ej. ISO-8859-1  utf-8
resp.encoding = "utf-8"                         # decide tú, antes de usar resp.text

Sesiones y reintentos

Una Session reutiliza la conexión (más rápido) y permite configurar reintentos automáticos con espera creciente (backoff) para errores temporales.

from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

def crear_sesion() -> requests.Session:
    reintentos = Retry(
        total=3,
        backoff_factor=1,                       # espera 1 s, 2 s, 4 s...
        status_forcelist=[429, 500, 502, 503, 504],
    )
    sesion = requests.Session()
    sesion.mount("http://", HTTPAdapter(max_retries=reintentos))
    sesion.mount("https://", HTTPAdapter(max_retries=reintentos))
    sesion.headers["User-Agent"] = "TalentScopeBot/0.3"
    return sesion

sesion = crear_sesion()
try:
    resp = sesion.get(url, timeout=10)
    resp.raise_for_status()
except requests.exceptions.Timeout:
    ...   # el servidor tardó demasiado
except requests.exceptions.RequestException as e:
    ...   # cualquier otro problema de red o HTTP
Error frecuente

Capturar except Exception: pass. El scraper "funciona" pero devuelve cero ofertas y nadie se entera. Registra el error (capítulo 16) o lanza una excepción propia con un mensaje claro.

Practica

Con el portal corriendo (python -m http.server 8000 --directory portal_mock), pide /ofertas/pagina-99.html. ¿Qué código de estado devuelve? ¿Qué hace raise_for_status()?

Extraer datos con BeautifulSoup

Apoya HU-10HU-11HU-16HU-23

BeautifulSoup convierte el HTML en un árbol que puedes recorrer con selectores CSS, los mismos que usas en una hoja de estilos. Antes de escribir código, abre la página en el navegador, pulsa F12 e inspecciona el elemento que te interesa.

from bs4 import BeautifulSoup

html = """
<div class="producto" data-sku="L-200">
  <h2><a href="/item/L-200">Portátil 14"</a></h2>
  <span class="precio">$ 2.899.000</span>
  <ul class="specs"><li>16 GB</li><li>SSD 512</li></ul>
</div>
"""
soup = BeautifulSoup(html, "html.parser")

for prod in soup.select("div.producto"):          # select -> lista de elementos
    enlace = prod.select_one("h2 a")               # select_one -> primer elemento o None
    print(prod["data-sku"])                        # atributo del elemento
    print(enlace.get_text(strip=True))             # texto sin espacios extra
    print(enlace["href"])                          # /item/L-200
    print([li.get_text(strip=True) for li in prod.select("ul.specs li")])

Elementos que pueden faltar

Si select_one no encuentra nada devuelve None, y None.get_text() rompe el programa. Usa una función auxiliar:

def texto(padre, selector, defecto=None):
    el = padre.select_one(selector)
    return el.get_text(strip=True) if el else defecto

Paginación

El patrón es un ciclo: procesa la página, busca el enlace a la siguiente, conviértelo en URL absoluta con urljoin y repite hasta que no haya más. Siempre pon un límite para no quedar en un ciclo infinito.

from urllib.parse import urljoin

url = "https://tienda.ejemplo/catalogo/1"
visitadas = 0
while url and visitadas < MAX_PAGINAS:
    soup = BeautifulSoup(descargar(url), "html.parser")
    procesar(soup)
    siguiente = soup.select_one("a.siguiente")
    url = urljoin(url, siguiente["href"]) if siguiente else None
    visitadas += 1

urljoin("http://localhost:8000/ofertas/pagina-1.html", "pagina-2.html")
# 'http://localhost:8000/ofertas/pagina-2.html'
urljoin("http://localhost:8000/ofertas/pagina-1.html", "../oferta/ET-1.html")
# 'http://localhost:8000/oferta/ET-1.html'
Separa descargar de parsear

Una función recibe una URL y devuelve HTML; otra recibe HTML y devuelve diccionarios. La segunda se puede probar con archivos guardados sin internet (capítulo 17). Así está hecho parsear_listado en el código heredado.

Scraping responsable

Apoya HU-12HU-16HU-19

Un scraper hace peticiones al servidor de otra organización. Hacerlo mal puede saturarlo, violar sus términos o recolectar datos personales. Reglas del proyecto:

  • Lee robots.txt y respeta lo que prohíbe y el Crawl-delay.
  • Identifícate con un User-Agent honesto.
  • Haz pausas entre peticiones y no pidas dos veces lo que ya tienes (HU-19).
  • Revisa los términos de uso del sitio. Si ofrece una API, úsala.
  • No recolectes datos personales (nombres, correos, teléfonos de personas).
  • En este curso solo scrapeamos el portal simulado y sitios hechos para practicar, como Fake Jobs de Real Python o Books to Scrape.
import time
from urllib.robotparser import RobotFileParser

robots = RobotFileParser("http://localhost:8000/robots.txt")
robots.read()
agente = "TalentScopeBot"

print(robots.can_fetch(agente, "http://localhost:8000/ofertas/pagina-1.html"))  # True
print(robots.can_fetch(agente, "http://localhost:8000/admin/"))                 # False
pausa = robots.crawl_delay(agente) or 1

for url in urls:
    if not robots.can_fetch(agente, url):
        continue
    html = descargar(url)
    time.sleep(pausa)

Expresiones regulares para texto sucio

Apoya HU-13HU-14HU-25HU-33

Una expresión regular describe un patrón de texto. Sirve para sacar números de frases como "Desde $ 1.250.000" o detectar palabras en una descripción. Escríbelas con cadenas crudas r"..." para que las barras invertidas no se interpreten.

PatrónSignificaCoincide en "Precio: $ 1.250.000 COP"
\dUn dígito1, 2, 5...
\d+Uno o más dígitos1 · 250 · 000
[\d.]+Dígitos o puntos, uno o más1.250.000
\s*Cero o más espacios
(COP|USD)Grupo: una alternativa u otraCOP
\bJava\b"Java" como palabra completano coincide en "JavaScript"
(?i)Ignorar mayúsculas
 
import re

texto = "Oferta: entre $ 1.250.000 y 1.890.000 COP"
numeros = re.findall(r"\d[\d.]*", texto)          # ['1.250.000', '1.890.000']
valores = [int(n.replace(".", "")) for n in numeros]
print(min(valores), max(valores))                  # 1250000 1890000

m = re.search(r"(?P<moneda>COP|USD|EUR)", texto)    # grupo con nombre
print(m.group("moneda") if m else None)            # COP

# "2,5 kg" -> 2.5   (coma decimal)
peso = float(re.search(r"(\d+(?:,\d+)?)\s*kg", "Peso: 2,5 kg").group(1).replace(",", "."))

# Palabras completas, sin importar mayúsculas
re.search(r"\bpython\b", "Buscamos dev PYTHON senior", flags=re.IGNORECASE)  # coincide
Error frecuente

En Colombia el punto separa miles (4.500.000) pero en dólares suele ser la coma (1,500). Antes de convertir, decide qué significa cada símbolo según la moneda. Escribe un test por cada formato real que encuentres.

Practica

Prueba tus patrones en regex101.com (elige el modo Python). Recorre todas las páginas del portal y junta en un set los textos de salario distintos que existen: esa lista es tu mejor fuente de casos de prueba.

Encontrar la fila de encabezados automáticamente

def fila_encabezado(ruta, hoja, esperadas: set[str], max_filas=10) -> int:
    crudo = pd.read_excel(ruta, sheet_name=hoja, header=None, nrows=max_filas)
    puntajes = crudo.apply(lambda fila: len(esperadas & set(fila.astype(str))), axis=1)
    return int(puntajes.idxmax())

Tildes y variantes

import unicodedata

def sin_tildes(texto: str) -> str:
    descompuesto = unicodedata.normalize("NFD", texto)       # "á" -> "a" + tilde
    return "".join(c for c in descompuesto if unicodedata.category(c) != "Mn")

sin_tildes("Bucaramanga, Santander · Pereira · Popayán").lower()
# 'bucaramanga, santander · pereira · popayan'

Validar datos

Apoya HU-15HU-36HU-38HU-46

Validar es separar lo bueno de lo malo y explicar por qué. Nunca borres filas en silencio: guarda las rechazadas con su motivo para el reporte de calidad.

OBLIGATORIAS = ["producto", "precio", "ciudad"]

def validar(df: pd.DataFrame) -> tuple[pd.DataFrame, pd.DataFrame]:
    faltan = set(OBLIGATORIAS) - set(df.columns)
    if faltan:
        raise ValueError(f"Faltan columnas obligatorias: {sorted(faltan)}")

    motivos = pd.Series("", index=df.index)
    motivos[df["producto"].isna()] += "producto vacío; "
    motivos[~df["precio"].between(1_000, 50_000_000)] += "precio fuera de rango; "
    motivos[df.duplicated()] += "duplicado; "

    malas = df[motivos != ""].assign(motivo=motivos[motivos != ""])
    buenas = df[motivos == ""]
    return buenas, malas

# Calidad por columna
calidad = (df.isna().mean() * 100).round(1).rename("pct_nulos").to_frame()

        PRIMARY KEY (sku, fuente)

index=FalseNo escribir el índice de pandas. Casi siempre lo quieres.

Errores frecuentes

Un reporte HTML se abre en cualquier navegador y se puede enviar por correo. Para que sea un solo archivo, las imágenes van incrustadas en base64.

import base64
from io import BytesIO

def figura_a_base64(fig) -> str:
    buffer = BytesIO()
    fig.savefig(buffer, format="png", dpi=120, bbox_inches="tight")
    return base64.b64encode(buffer.getvalue()).decode()

tabla = resumen.to_html(classes="tabla", float_format=lambda x: f"{x:,.0f}", border=0)

<html lang="es"><meta charset="utf-8"><title>Reporte semanal</title>
<style>body{{font-family:sans-serif;max-width:900px;margin:auto}}
.tabla td,.tabla th{{padding:4px 10px;border-bottom:1px solid #ddd}}</style>
<h1>Reporte semanal</h1>
<p>{hallazgo}</p>
